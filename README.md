# bountyfarmer 😈

Joke / test repo — not a real bounty program and no real money is offered.

- `index.js` — prints a hello-world "claim your bounty" line.
- `bounty.sh` — generates a random joke bounty issue (random $-amount and
  feature name) and files it, via `gh issue create`, against the
  `OmniBlocks/bountyfarmer` repo. For fun only.
